# Memory Game

Игра на поиск пар. 16 карточек, 8 пар.

## Запуск локально

1. Клонировать репозиторий:
   `git clone https://github.com/.../memory-game.git`
2. Перейти в ветку `memory-game`:
   `git checkout memory-game`
3. Открыть `index.html` в браузере
   (или запустить `npx serve .`).

## Стек
- HTML, CSS, JavaScript (ES-модули)
- localStorage для таблицы лидеров
- Без сторонних библиотек
